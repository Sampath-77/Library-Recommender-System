# Contextual Library Book Recommendation System

This project recommends relevant books based on user input using
Natural Language Processing techniques instead of traditional
genre-based filtering.

## Problem Statement
Traditional library systems rely on fixed categories and tags,
which fail to capture the true intent behind a reader’s query.

## Solution
A content-based recommendation system that understands user queries
using NLP and suggests contextually similar books.

## Tech Stack
- Python
- Scikit-learn
- Pandas, NumPy
- TF-IDF Vectorization
- Cosine Similarity
- Streamlit

## Workflow
1. User enters a natural language query
2. Text preprocessing (cleaning, tokenization, stopword removal)
3. TF-IDF vectorization
4. Cosine similarity computation
5. Top relevant books are recommended

## Outcome
The system successfully provides accurate and meaningful
recommendations based on semantic similarity.
